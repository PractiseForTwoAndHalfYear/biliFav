# biliFav — B站收藏整理器

输入 B 站 UID，拉取公开收藏夹视频，自动分类（听/看、标题主题、时长区间），支持标记已看、加精、拖拽评级、每日清单计划。

## 功能

- 🔍 **输入 UID** — 拉取公开收藏夹列表
- 📂 **选择收藏夹** — 多选需要整理的收藏夹
- 🚗 **自动分类** — 听/看 自动归类，支持 UP 主白名单
- 🏷️ **主题/时长筛选** — 按标题内容主题和视频时长区间整理收藏
- ⭐ **标记系统** — 已看、加精、手动覆盖分类
- 📅 **每日清单** — 按时间目标自动打包未看视频
- 🏆 **拖拽评级** — 5 档位评级（夯→拉），拖拽交互
- 💾 **本地存储** — 所有数据保存在浏览器 localStorage
- 🧩 **分类规则管理** — 分类算法规则集中维护在 `classifiers/`

## 快速开始

直接双击 `bili-fav-fast.html` 用浏览器打开，或在项目目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

详细规范请参阅 [CLAUDE.md](CLAUDE.md)。
