# 分类算法管理

本目录集中维护 `bili-fav-fast.html` 中使用的自动分类规则。

当前项目仍保持单文件 HTML 可直接打开，因此页面运行时不会动态加载这里的 JS 文件；这里是分类算法的可维护源文件。修改分类规则后，需要同步更新 `bili-fav-fast.html` 中对应的内嵌逻辑，并更新 `src/javascript/*.md` 的行号映射。

## 文件

- `classification-rules.js`：听/看分类、标题主题标签分类、时长分类的纯函数和规则表。

## 当前分类方式

- 收听/观看：根据 UP 主白名单、标题/简介关键词、B 站分区判断为 `listen` 或 `watch`。
- 标题主题：根据标题、简介、分区中的关键词打上内容主题标签，例如 `编程开发`、`AI/科技`、`游戏`、`生活经验`。
- 时长区间：根据视频秒数分为 `短视频`、`中等`、`长视频`、`超长`。
